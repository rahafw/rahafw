## 🚀 Projects

### ⚽ FIFA World Cup History Dashboard
> *Python · Pandas · Power BI · DAX*

An interactive Power BI dashboard exploring 92 years of World Cup history (1930–2022), built ahead of the 2026 tournament. Covers KPI cards, goal trends, title distributions, and team performance — with a custom dark navy & gold theme and a slide-out filter panel.

🔗 [View Repository](https://github.com/rahafw/fifa-worldcup-dashboard)

---

### 🌟 Future Star — Football Talent Prediction
> *Python · Pandas · NumPy · Scikit-learn · XGBoost · FastAPI · Docker · Google Cloud Run*

A machine learning project that predicts whether a young footballer has the potential to become a future star — built to support **Saudi football academies** and aligned with **Vision 2030**. Uses advanced per-90 metrics (xG, xA, progressive passes, defensive actions) and an XGBoost classifier to generate an interpretable probability score. Deployed as a FastAPI service on Google Cloud Run.

Developed as part of the **Saudi Digital Academy Bootcamp in partnership with Le Wagon**, Riyadh.

🔗 [View Repository](https://github.com/rahafw/future_stars)
